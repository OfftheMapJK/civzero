# Read the skills without the station

The CivicNode skills are plain HTML pages: any computer or phone can read them, without a server or the Internet.

## 1. Principle

The skills site works without JavaScript or a server. Open the home file in a browser, and all the skills can be browsed through links. Wikipedia, which is larger, is read with the Kiwix app.

## 3. Step by step

### Step 1: Get the archive

- **Action:** copy the skills folder from a station, a stick or another phone (*Pass skills from phone to phone* skill).
- **Check:** the folder contains an `index.html` file.
- **Source:** not applicable

### Step 2: On a computer

- **Action:** open `index.html` in a browser, with a double click.
- **Check:** the CivicNode home page appears and the links lead to the skills.
- **Source:** not applicable

### Step 3: On a phone

- **Action:** open `index.html` from the file manager. Some recent mobile browsers block opening local files directly: in that case, the Kiwix app is the most reliable way. For Wikipedia, use Kiwix with a `.zim` file. [TO CHECK: version of the skills in Kiwix (ZIM) format, not yet published]
- **Check:** the skills appear on the phone.
- **Source:** [SOURCE NEEDED]

### Step 4: From a stick on a phone

- **Action:** plug in the stick with an OTG adapter, then open `index.html` from the stick or copy the folder to the phone.
- **Check:** the skills appear.
- **Source:** [SOURCE NEEDED]

### Step 5: Check the version

- **Action:** read the sync date on the home page.
- **Check:** you know how old your copy is.
- **Source:** not applicable

## 4. If you get stuck

- **Step 2 — the page appears without formatting.** The folder was copied incompletely: copy it again in full.
- **Step 3 — the phone refuses to open the file.** Try another browser, or ask for a version in Kiwix format.
- **Step 4 — the stick is not recognised.** The phone may not support OTG: go through a computer.
