## 1. Pourquoi une marque

Tout ce que CivicNode publie est ouvert : les fiches sont sous licence CC BY-SA 4.0, le code sous AGPL-3.0. Chacun peut les copier, les modifier et les redistribuer.

Le nom et le logo, eux, disent autre chose : que les fiches que vous lisez sont passées par notre chaîne de vérification (voir [Nos sources et notre méthode](a-sources-et-methode.html)). Si n'importe quelle version modifiée pouvait porter ce nom, il ne garantirait plus rien. C'est pourquoi le nom « CivicNode » et le logo ne sont pas sous CC BY-SA : ce sont les marques du projet.

## 2. Ce que vous pouvez faire sans rien demander

- Parler du projet, le citer, le critiquer, écrire à son sujet.
- Faire un lien vers le site ou le dépôt.
- Montrer le logo, tel quel, pour désigner le projet (article, affiche, présentation, liste de ressources).
- Monter une « station CivicNode » et l'appeler ainsi, tant qu'elle sert le corpus officiel sans le modifier. Vous pouvez y ajouter d'autres contenus (Wikipédia, cartes, documents locaux) s'ils sont clairement séparés des fiches.
- Citer CivicNode comme source de ce que vous reprenez : la licence des fiches le demande.

## 3. Ce que vous pouvez faire en le disant

Vous pouvez modifier les fiches, les traduire, les adapter à votre région : la licence le permet. Dans ce cas :

- donnez un autre nom à votre version, et n'utilisez pas le logo comme le vôtre ;
- dites d'où elle vient, par exemple « basé sur CivicNode » ;
- dites que vous l'avez modifiée, et gardez la licence CC BY-SA 4.0.

Une correction ou une traduction peut aussi rejoindre le corpus officiel : proposez-la, elle suivra la même chaîne de vérification que les autres fiches.

## 4. Ce qui n'est pas permis

- Diffuser des fiches modifiées sous le nom « CivicNode » ou avec son logo.
- Laisser croire à un partenariat, à un soutien ou à une validation du projet qui n'existent pas.
- Collecter de l'argent, des dons ou des données au nom du projet.
- Modifier le logo, ou s'en servir comme logo d'un autre projet, d'un produit ou d'une organisation.

## 5. Un doute, une demande

Écrivez à hello@civicnode.eu. Si votre usage n'entre dans aucun des cas ci-dessus, demandez : la réponse est le plus souvent oui.

## 6. Où en est la marque

Le logo est en cours de création. Le nom et le logo ne sont pas encore déposés : le dépôt est prévu, et cette page dira alors qui en est le titulaire. D'ici là, cette politique dit comment nous demandons que le nom soit utilisé.
